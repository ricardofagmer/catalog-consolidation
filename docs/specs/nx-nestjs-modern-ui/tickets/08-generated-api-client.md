# 08: Generated api-client

**What to build:** An `api-client` library generated from the API's OpenAPI document by an Nx target, typed with openapi-typescript and openapi-fetch, treated as a build output and never hand-edited. The generate target depends on the API's OpenAPI export so the client cannot silently disagree with the backend.

**Blocked by:** 07

**Closes checks:** none — prefactor (enables 09; the contract itself is proven in 07)

**Status:** done

- [ ] `nx run api:openapi` writes the document without starting a long-lived server, and `nx run api-client:generate` produces the typed client from it
- [ ] The client compiles, exposes every endpoint from the contract and is excluded from hand edits (marked generated, git-ignored or regenerated by build)
- [ ] Changing a DTO field in the API changes the client types on regeneration, and the web project's typecheck would see it
- [ ] The project is tagged so that only `web` may depend on it among the frontend tags
